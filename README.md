## Upload this update
1. Extract the ZIP.
2. Open the Annjeleen_Portfolio folder.
3. On your GitHub repository, choose Add file > Upload files.
4. Drag index.html, README.md and the assets folder onto the upload area. Upload their contents at the repository root, not inside an additional Annjeleen_Portfolio folder.
5. Commit the changes. Same-named files will be updated.
6. Allow GitHub Pages to republish, then refresh the website.
7. Check the photo, CV download, navigation, email, phone and WhatsApp links.
